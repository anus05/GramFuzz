# GramFuzz 0.1.0 release notes (draft)

**Status: not published.** This draft does not represent a GitHub Release,
tag, or published package.

No open-source license is declared for GramFuzz. This draft grants no rights
to use, modify, or redistribute the project.

GramFuzz 0.1.0 prepares the initial framework release with:

- An installable Python package and authorization-confirmed CLI.
- Bounded CFG generation, configurable mutations, scoped HTTP requests, and
  evidence-bearing response analysis with heuristic risk scores.
- SQLite persistence and JSON/HTML reporting.
- A loopback-only controlled test application and reproducible evaluation
  runner.
- Packaged safe starter grammars for SQL syntax variation, benign reflected
  markup, and path validation inputs.
- Documentation for authorization requirements, limitations, and
  contributions.

### Safety and limitations

The scanner is intended only for explicitly authorized testing. Signals and
risk scores are not confirmed vulnerabilities or CVSS scores. The starter
grammars do not execute SQL, execute browser script, or access sensitive
filesystem paths. See [SECURITY.md](../../SECURITY.md) and
[the security guide](../security.md) before use.

### Compatibility

The package declares Python `>=3.10`; its Windows, Ubuntu, and macOS matrix
must pass before compatibility with those combinations is claimed. This draft
is not evidence that the CI jobs have completed.
